# Kids Facts Book — Quiz & Answer Key Download Logic

From now on, update the Kids Facts Book application so that the **“LEVEL 1 to 5 — FACT DETECTIVE QUIZ”** section in the generated PDF and the **“KNOWLEDGE QUIZ ANSWER KEY”** are consistently generated and downloadable in both **Excel (.xlsx)** and **TXT (.txt)** formats.

### 1. FACT DETECTIVE QUIZ — PDF

The generated Kids Facts Book PDF must contain the complete:

**LEVEL 1 to 5 — FACT DETECTIVE QUIZ**

The PDF quiz must remain part of the book manuscript and must include all five levels in the correct order:

**LEVEL 1 → LEVEL 2 → LEVEL 3 → LEVEL 4 → LEVEL 5**

Do not remove, replace, or omit the quiz when exporting the PDF.

### 2. KNOWLEDGE QUIZ ANSWER KEY — Excel

Generate a complete **Knowledge Quiz Answer Key Excel file (.xlsx)** containing the answers corresponding exactly to every question in the PDF quiz.

The Excel file must:

* Include all quiz levels from **Level 1 to Level 5**.
* Preserve the exact quiz/question numbering used in the PDF.
* Store each question number, level, question, and correct answer in separate columns.
* Keep the answer mapping 100% synchronized with the PDF-generated quiz.
* Regenerate automatically whenever the quiz content changes.
* Never use answers from an older book or previously generated manuscript.

Recommended columns:

**Level | Question No. | Question | Correct Answer**

### 3. KNOWLEDGE QUIZ ANSWER KEY — TXT

Also generate a complete **Knowledge Quiz Answer Key TXT file (.txt)** using the same answer data as the Excel file.

The TXT file must:

* Include **Level 1 through Level 5**.
* Preserve the exact question numbering.
* Contain the corresponding correct answer for every question.
* Use the same latest answer dataset used to create the Excel file.
* Never contain stale answers from a previous book.

Recommended format:

**LEVEL 1**

1. Answer
2. Answer
3. Answer

**LEVEL 2**

1. Answer
2. Answer
3. Answer

Continue through **LEVEL 5**.

### 4. DOWNLOAD BUTTONS

Add separate download controls so the user can download both answer-key formats:

**Download Knowledge Quiz Answer Key — Excel (.xlsx)**

**Download Knowledge Quiz Answer Key — TXT (.txt)**

Both buttons must be available after quiz generation/export and must download the answer key for the **currently generated book only**.

### 5. SINGLE SOURCE OF TRUTH

The quiz questions and answer key must use one current in-memory data source.

Required flow:

**Generate Quiz → Store Current Quiz Data → Generate PDF Quiz → Generate Excel Answer Key → Generate TXT Answer Key**

Do not independently recreate the answers from different sources.

The Excel and TXT files must be generated from the exact same current answer-key dataset.

### 6. BOOK ISOLATION

When a new Kids Facts Book is created:

* Clear all quiz data belonging to the previous book.
* Generate a completely new quiz dataset for the new book.
* Generate a new Knowledge Quiz Answer Key Excel file.
* Generate a new Knowledge Quiz Answer Key TXT file.
* Never reuse the previous book's quiz answers.
* Never append the new book's answers to an older answer key.

Each book must have its own isolated quiz and answer-key state.

### 7. FILE NAMING

Use book-specific filenames to prevent confusion or accidental overwriting.

Recommended naming:

**`[BookName]_Knowledge_Quiz_Answer_Key.xlsx`**

**`[BookName]_Knowledge_Quiz_Answer_Key.txt`**

The generated files must use the current book name/code where available.

### 8. EXPORT VALIDATION

Before enabling the download buttons, validate that:

* Level 1–5 quiz data exists.
* Every question has an answer.
* Question numbering is complete.
* Excel and TXT contain the same number of answers.
* Excel and TXT contain matching answers for every question.
* The exported answer count matches the PDF quiz question count.

If validation fails, do not generate an incomplete answer key. Show a clear error indicating that the quiz/answer-key data is incomplete.

### 9. IMPORTANT BUG PREVENTION

Fix the existing stale-data behavior so that generating a new Kids Facts Book never leaves the previous book's **Knowledge Quiz Answer Key** attached to the new book.

The answer key must always be regenerated from the **newly created book's current quiz dataset**.

### 10. FINAL REQUIRED RESULT

For every newly generated Kids Facts Book, the application must provide:

**PDF**

* LEVEL 1 to 5 — FACT DETECTIVE QUIZ

**Excel**

* KNOWLEDGE QUIZ ANSWER KEY (.xlsx)

**TXT**

* KNOWLEDGE QUIZ ANSWER KEY (.txt)

All three outputs must represent the **same book, same quiz questions, same numbering, and same correct answers** with no stale or cross-book data.
