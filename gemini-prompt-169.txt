## Bug Report & Feature Request — "All JPG Collages (ZIP)" Output Quality (Batch Preset Renderer / SVG Recolor)

### 1. Issue Summary
When processing SVG files through the **"Batch Preset Renderer"** option inside the **"SVG Recolor"** section, the resulting **"All JPG Collages (ZIP)"** download produces **very poor-quality JPG output**. The rendered collages exhibit:

- **Blur** — edges, text, and fine details appear soft and undefined
- **Noise** — visible grain and artifacts across solid and gradient areas
- **Pixelation** — jagged, blocky edges on curves, icons, and diagonal lines

This makes the **"All JPG Collages (ZIP)"** output unusable for professional, print, or commercial purposes — unlike the SVG and PNG collage outputs, which render correctly.

---

### 2. Root Cause (Likely)
The current JPG collage conversion logic may be:

- Rasterizing the SVG collage at a **low default resolution** (e.g., 72 DPI or screen-size only)
- Encoding JPGs at a **low quality value** (e.g., 60–70%)
- **Scaling down** the collage canvas instead of rendering at full target dimensions
- **Lacking anti-aliasing / supersampling** before final downscaling
- Ignoring the **user-selected DPI, width, height, and quality settings**

---

### 3. Requested Fix — High-Quality JPG Collage Output
Please revise the **logic/code** so that the **"All JPG Collages (ZIP)"** output:

- Rasterizes each SVG collage at the **full target resolution** (based on user-selected width, height, and DPI)
- Applies **anti-aliasing / supersampling** before final downscaling
- Encodes JPGs at **90–100% quality** by default (or follows the user's quality selection)
- Shows **no compression artifacts** in flat-color or gradient areas
- Matches the **visual fidelity of the original SVG collage** as closely as possible
- Maintains **consistent quality across all collages** inside the ZIP

---

### 4. Additional Request — Real-Time File Size Display
After the user makes a selection (DPI, width, height, quality, format, etc.), the **estimated file size** should be displayed in **real time**.

**Examples:**
- `500 KB`
- `2 MB`
- `1.4 MB`

**Requirements:**
- Updates instantly when the user changes **DPI, width, height, quality, or format**
- Clearly visible near the download/preview area
- Accurate within a reasonable margin (±10%)
- Applies to both **single collage** and **"All JPG Collages (ZIP)"** bulk download
