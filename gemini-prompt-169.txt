## Bug Report & Feature Request — "Batch Preset Renderer" (SVG Recolor Section)

### 1. Issue Summary
When processing SVG files through the **"Batch Preset Renderer"** option within the **"SVG Recolor"** section of the website, the resulting **JPG output is of very poor quality**. The rendered JPGs exhibit:

- **Blur** — edges and fine details appear soft and undefined
- **Noise** — visible grain and artifacts across solid color areas
- **Pixelation** — jagged, blocky edges on curves, text, and diagonal lines

This makes the JPG output unusable for professional, print, or commercial purposes.

---

### 2. Root Cause (Likely)
The current JPG conversion logic may be:

- Rendering at a **low default resolution** (e.g., 72 DPI or screen-size only)
- Using a **low JPEG quality value** (e.g., 60–70%) during encoding
- **Rasterizing the SVG at a fixed canvas size** instead of scaling to the user-selected dimensions
- **Lacking anti-aliasing** or supersampling before downscaling
- Ignoring the **DPI and width/height settings** the user selects

---

### 3. Requested Fix — High-Quality JPG Output
Please revise the **logic/code** so that:

- SVGs are **rasterized at the full target resolution** (based on user-selected width, height, and DPI)
- **Anti-aliasing / supersampling** is applied before final downscaling
- **JPEG quality** defaults to **90–100%** (or follows the user's quality selection)
- **No compression artifacts** appear in flat-color or gradient areas
- Output matches the **visual fidelity of the original SVG** as closely as possible

---

### 4. Additional Request — Real-Time File Size Display
After the user makes a selection (resolution, DPI, quality, format, etc.), the **estimated file size** should be displayed in **real time**.

**Examples:**
- `500 KB`
- `2 MB`
- `1.4 MB`

**Requirements:**
- Updates instantly when the user changes **DPI, width, height, quality, or format**
- Clearly visible near the download/preview area
- Accurate within a reasonable margin (±10%)
